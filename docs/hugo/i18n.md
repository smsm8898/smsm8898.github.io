# i18n/

## 용도

다국어 사이트의 **번역 문자열 테이블** (`ko.yaml`, `en.yaml`, …).
템플릿의 `{{ i18n "readMore" }}` 같은 키가 언어별 문자열로 치환된다.

## 언제 쓰게 되나

두 경우:

1. **블로그를 다국어(한/영)로 확장할 때** — `hugo.yaml`에 `languages` 설정을 추가하고
   글을 `foo.md` / `foo.en.md`처럼 언어별로 두는 구조와 세트로 쓴다.
2. **테마 UI 문자열을 바꾸고 싶을 때** — PaperMod가 자체 i18n을 내장하고 있어서
   ("Read more", "Home" 등), 같은 키를 프로젝트 `i18n/ko.yaml`에 정의하면
   union mount 규칙으로 프로젝트 값이 이긴다.

한국어 단일 언어인 지금은 쓸 일 없음.
