이 글은 **Recommendation** 시리즈의 출발점입니다. 특정 구현 이야기가 아니라, 추천 알고리즘 각 계열의 개념 — 정의, 동작 원리, 장단점 — 을 정리합니다.

## 1. 왜 필요한가?
- **배경(정보 과잉)**: 상품·콘텐츠가 수십만 개면 사용자는 원하는 것을 스스로 다 찾지 못한다. 검색은 "무엇을 원하는지 아는" 사용자의 도구 — 모를 때, 애매할 때 대신 골라서 보여주는 장치가 필요
- **해결책(추천 시스템)**: 축적된 데이터로 "이 사용자가 다음에 좋아할 것"을 예측하는 시스템. 고전 분류는 **무엇을 재료로 쓰느냐**로 계열을 나누는데, 그 밖에도 축이 몇 개 더 있다 (아래 로드맵)

## 2. 무엇을 재료로 쓰는가?
- **인기 신호**: 모두의 행동 집계 (조회수·판매량·투표) — 사용자를 구분하지 않는다
- **행동 이력**: 누가 무엇을 봤나·샀나·평가했나 — user-item 상호작용 행렬
- **아이템 속성**: 카테고리·텍스트·이미지·가격 — 콘텐츠 그 자체

## 3. 구성 요소

| 계열 | 핵심 아이디어 | 재료 |
|---|---|---|
| Popular (비개인화) | 인기를 시간 감쇠로 집계 — "역대"가 아닌 "요즘" 인기 | 인기 신호 |
| Collaborative Filtering | "너와 비슷한 사람들이 좋아한 것" — 취향의 유사성은 행동에 드러난다 | 행동 이력 |
| Content-Based | "네가 좋아한 것과 속성이 비슷한 것" | 아이템 속성 + 개인 이력 |
| Hybrid | 계열들의 결합 — 서로의 약점(콜드스타트·필터 버블·인기 편향)을 보완 | 위 전부 |

* 이 네 줄이 곧 **고전 분류**(교과서 분류)이고, 시리즈의 첫 네 편이다.

## 4. 시리즈 로드맵 — 네 개의 축
고전 분류는 "무엇을 재료로 쓰나" **한 축**을 나눈 것이다. 실무에서 자주 쓰이는 주제들은 이 축의 5번째·6번째 항목이 아니라, **다른 축**에 놓인다.

| 축 | 답하는 질문 | 편 |
|---|---|---|
| 재료 | 무엇을 재료로 쓰나 | Popular, Collaborative Filtering, Content-Based, Hybrid |
| 문제 설정 | 문제를 어떻게 정의하나 | Session-based / Sequential, Context-aware |
| 표현 학습 | 표현을 어떻게 학습하나 | Embedding & Vector Search, Deep Ranking |
| 학습 방식 | 어떻게 배우나 | Bandit & Exploration |

- **문제 설정** 축은 입력의 모양을 바꾼다. 세션은 순서 없는 행렬을 **시퀀스**로 다시 정의하고, 컨텍스트는 `user × item` 행렬에 **차원을 하나 더** 붙인다. 둘 다 특정 모델과 무관한 문제 정의이므로, 딥러닝 없이도 성립한다
- **표현 학습** 축은 사람이 정한 유사도·규칙 대신 **표현 자체를 학습**한다. 임베딩과 벡터 검색(최근접 이웃 서빙), 신경망 랭킹 모델이 여기 속한다. MF가 그 원형이었다는 점에서 CF·CB의 현대적 수렴이기도 하다
- **학습 방식** 축은 패러다임이 다르다. 위의 모든 계열이 **과거 로그로 학습**하는데, 그 로그는 과거의 추천 정책이 만든 것이다. 추천하지 않은 것은 데이터가 없고, 데이터가 없으니 계속 추천되지 않는다 — 이 피드백 루프를 탐색(exploration)으로 깨는 계열

## 5. 구체적 사례 — 왜 하나로는 안 되는가
1. 첫 방문 사용자: 이력이 없어 개인화가 불가능 → **Popular**가 받는다 (유저 콜드스타트)
2. 몇 번의 클릭: 이력이 얇아도 방금 본 아이템의 속성으로 비슷한 것을 찾을 수 있다 → **Content-Based**
3. 이력이 쌓이면: "이 사람과 비슷하게 행동한 사람들"이 보이기 시작한다 → **CF**가 가장 강력해지는 구간
4. 신상품 등록: 행동 이력이 0이라 CF는 다루지 못한다 → 속성으로 다루는 **Content-Based**가 커버 (아이템 콜드스타트)
- 계열마다 강한 구간이 다르다. 그래서 실제 서비스는 결국 **Hybrid**로 간다
